[04.B / Research interests]Tap a line to open

Research
interests

  1. Developing a communication interface between blind and deaf people. A deaf person communicates in sign language and a blind person through speech; with no common mode between the two, the work develops an algorithm that acts as an interface — helping both groups interact, improve their lives and contribute to society on par with other citizens.

  2. Minutiae detection in fingerprint images using binary detection and direct grayscale detection. Feature extraction covers local features such as ridge endings and bifurcations, and global features such as core and delta points. Matching compares stored template data with the input image; few minutiae suffice, and the whole pipeline — pre-processing, extraction and matching — takes 8–15 seconds.

  3. Extracts a graph from each character for classification, built from its closed regions and junction points. Classification is independent of the font and size of printed text, and the system delivers reasonable performance.

  4. Developing novel image-processing algorithms for the navigation of unmanned air vehicles (UAVs) and for medical image processing.

    • Designed a robot for object tracking — “JUNIOR” was developed to track objects.
    • Degraded character recognition.
